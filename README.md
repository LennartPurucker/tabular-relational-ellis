# AI for Tabular & Relational Data: What's Next?

Website for our session at the [ELLIS UnConference 2026](https://ellis-unconference.github.io/) (Tuesday 8 December 2026, Paris).

Live at <https://lennartpurucker.github.io/tabular-relational-ellis/>

The whole site is `index.html`: plain HTML and CSS with no build step. Edit it and push to `main`, and GitHub Pages redeploys within a minute or two.

- **Photos:** put them in `img/` and add `<img src="img/name.jpg" alt="">` inside the person's `.avatar` span.
- **Poster form:** once the Google Form exists, point the three "Submit a poster" links at it (search for `TODO`).
